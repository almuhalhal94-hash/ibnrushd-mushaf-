# 📖 مصحف ابن رشد

مصحف تعليمي لقسم التربية الإسلامية – مدرسة ابن رشد الإعدادية للبنين (مملكة البحرين).
فيه آيات منهج التلاوة والحفظ للفصل الأول للصفوف: السادس الابتدائي، والأول والثاني والثالث الإعدادي.

## 🎙️ إضافة تسجيلات الطلاب (خطوة بخطوة)

1. **سمِّ كل تسجيل** برقم السورة ورقم الآية: `السورة_الآية.mp3`
   مثال: سورة الواقعة الآية 1 ← `56_1.mp3`.
2. **حطّ التسجيلات في مجلد الدرس:** `audio/<الصف>/<الدرس>/`
   مثال: الأول الإعدادي، درس الواقعة 1 ← `audio/7/t1/56_1.mp3` … `audio/7/t1/56_12.mp3`
   (رقم الصف والدرس من الجدول تحت.)
3. **سجّل اسم الطالب القارئ وحدّث القائمة:**
   ```
   python3 add_audio.py 7 t1 "اسم الطالب"
   ```
   السكربت يفحص الأسماء، ويكتب الآيات الموجودة والناقصة في `audio/audio.json`.
4. **ارفع:** `git add audio && git commit -m "تسجيلات …" && git push`
   بعد دقيقة يظهر في الدرس: زر ▶ لكل آية، و«تشغيل الدرس كامل»، و«بصوت الطالب: …».

ملاحظات:
- إذا ما في تسجيل للدرس، يظهر «التلاوة بصوت طلابنا – قريبًا» بدون أي خطأ.
- يكفي تسجيل بعض الآيات؛ زر التشغيل يظهر للآيات المسجّلة فقط.
- آيات الحفظ للسادس (`h1`, `h2`) تأخذ تسجيلات درس التلاوة نفسه (`t1` و`t6`) تلقائيًا.
- الأفضل: MP3 أحادي (mono) بجودة 64–96 kbps، عشان يكون خفيف على الجوال.
- إذا أرسلت التسجيلات لـ Claude: اكتب لكل ملف الصف والدرس واسم الطالب، وهو يسمّيها ويحطها ويشغّل السكربت.

## 🔧 للمطوّر

- **البيانات:** `python3 build.py [مسار ibnrushd-islamic]` يقرأ الخطط من موقع القسم، ويجلب النص والتفسير والمعاني، ويكتب `data/mushaf.json`.
  - النص: نص مصحف المدينة (مجمع الملك فهد، حفص) من quran.com (`text_qpc_hafs`)، ويُطابَق **حرفًا حرفًا** مع نص Tanzil. أي اختلاف يوقف البناء.
  - ألوان التجويد: من quran.com (`text_uthmani_tajweed`)، منقولة على نص المجمع بمحاذاة الحروف.
  - معاني الكلمات: «السراج في بيان غريب القرآن» (بيانات Quranpedia.net). التفسير: الميسر (Tanzil/alquran.cloud).
- **الخطوط (محلية):** `fonts/UthmanicHafs.woff2` (KFGQPC Uthmanic Script HAFS)، و Aref Ruqaa و Tajawal.
- **بدون نت:** `sw.js`. عند تغيير ملفات الواجهة، غيّر رقم الإصدار `V` في `sw.js`.
- **الملفات:** `index.html` + `style.css` + `app.js` (بدون مكتبات).
- **النشر:** GitHub Pages من الفرع `main` (الجذر). يُفعَّل من Settings ← Pages.
